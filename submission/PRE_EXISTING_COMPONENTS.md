## Data
All data is **synthetic**, generated by our own script: fictional stations, people and places. No real personal data. The ground-truth file (`data/evaluation/ground_truth.json`) is used only by offline evaluation and is never loaded or exposed by the application.

## Recorded model responses
`data/sample/model_fixtures/` holds responses that real Nemotron models returned (via Nightshift) for prompts built from the synthetic data, recorded with `scripts/record_fixtures.py` so the offline sample mode can replay them. They are model output about synthetic data; each replayed call is labelled `replayed` in the trace.
